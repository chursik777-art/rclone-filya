Privacy policy

rclone Filya is a personal tool used only by its owner. It runs rclone on the owner's own server to upload backup files to the owner's own Google Drive.

What data is accessed

The app uses the Google Drive drive.file scope. It can access only the files and folders it created itself. It cannot read any other files on the Drive.

How data is used and stored

Backup files are copied from the owner's server to the owner's Google Drive and nowhere else. The OAuth token is stored only in the rclone configuration on the owner's server.

Sharing

No data is sold, shared with or transferred to third parties. No analytics or advertising are used.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
